# Análisis de Datos de Accidentes de Tráfico en Madrid 2024

Este repositorio contiene un análisis exhaustivo de los accidentes de tráfico registrados en la ciudad de Madrid durante el año 2024, utilizando fuentes de datos abiertas y herramientas de procesamiento de datos para identificar patrones, puntos críticos y factores de riesgo en la seguridad vial.

---

## Descripción del proyecto
El objetivo principal de este proyecto es examinar la siniestralidad vial en Madrid a lo largo de 2024. A través del tratamiento y análisis de conjuntos de datos oficiales, se busca responder a preguntas clave sobre:
- **Distribución temporal:** horas punta, días de la semana y meses con mayor incidencia de accidentes.
- **Ubicación geográfica:** identificación de los distritos o zonas con mayor concentración de siniestros.
- **Tipología y gravedad:** análisis de los factores implicados (atropellos, colisiones, condiciones de la vía, etc.).

---

## Tecnologías, librerías y herramientas utilizadas
Este proyecto ha sido desarrollado utilizando un stack tecnológico enfocado en la ciencia de datos y el análisis estadístico:

- **Lenguaje de programación Python**

Lenguaje principal utilizado para la ingesta, transformación, análisis y modelado de los datos.

- **Librerías de análisis y procesamiento de datos**

Pandas: utilizado para la manipulación avanzada de estructuras de datos tabulares, filtrado, agregación y limpieza de los datasets de accidentes.

NumPy: empleado para operaciones numéricas eficientes y cálculos matriciales sobre los registros.

- **Librerías de visualización de datos**

Matplotlib: creación de gráficos estadísticos base (histogramas, gráficos de líneas y barras) para representar la evolución temporal de la siniestralidad.

Seaborn: generación de visualizaciones estadísticas avanzadas y mapas de calor (heatmaps) para correlaciones geográficas y temporales.

- **Entornos de desarrollo**

Jupyter Notebook / JupyterLab: entorno interactivo de desarrollo para la ejecución de bloques de código y la documentación visual del análisis paso a paso.

Visual Studio Code (VS Code): editor de código principal para la gestión de scripts y la estructuración general del proyecto.
